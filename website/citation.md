# Cite BrainLearn and its methods

BrainLearn has no stable release or archival DOI yet. For development work, cite the exact repository commit used by the analysis and include the workflow export, environment versions, input dataset version, and QC decisions with the research record.

```text
BrainLearn contributors. BrainLearn: local-first visual workflows for
reproducible neuroscience research. Development version. GitHub repository:
https://github.com/Brain-Learn/brainlearn (record the exact commit SHA).
```

The method citation should match the operation performed. The current EEG filter path uses:

- Gramfort et al. (2013), MNE software. [doi:10.3389/fnins.2013.00267](https://doi.org/10.3389/fnins.2013.00267)
- Pernet et al. (2019), MNE-BIDS. [doi:10.21105/joss.01896](https://doi.org/10.21105/joss.01896)

Check the version-specific MNE and MNE-BIDS citation guidance before manuscript submission. Dataset citations and licenses must be preserved independently of the software citation.
