Reproducible EEG examples
=========================

These examples use a small, deterministic, sample-bearing BIDS fixture with no
human data. The exact generator version, CC0-1.0 license, and checksums are
recorded in the repository's `synthetic EEG fixture manifest
<https://github.com/Brain-Learn/brainlearn/blob/main/examples/synthetic-eeg-bids-manifest.json>`_.

The fixture is ``brainlearn-synthetic-eeg-demo``, version ``1.0.0`` (BIDS
1.8.0), generated by ``create_synthetic_eeg_bids.py`` version ``1.0.0``. The
gallery environment uses Python 3.12, MNE-Python 1.13.2, and MNE-BIDS 0.20.0.
It creates 10 seconds of two-channel, 250 Hz signal with deterministic 10 Hz
and 12 Hz components, a 50 Hz component, and seeded noise. The expected output
is a plotted waveform in which the 50 Hz component is attenuated by an MNE
1–40 Hz FIR band-pass. The source fixture is regenerated from the checked-in
script and its SHA-256 manifest is verified separately by the engineering
gate. The generator SHA-256 is
``6fb7b822fba1f92460c00363525799c6e477f9014886d3d40a0d9ebcce56e409``; the
manifest also records SHA-256 for each generated input file.

The operation cites MNE-Python (`10.3389/fnins.2013.00267
<https://doi.org/10.3389/fnins.2013.00267>`_) and MNE-BIDS
(`10.21105/joss.01896 <https://doi.org/10.21105/joss.01896>`_). It is an
engineering demonstration only; it does not validate a filter for a study.

Each example reports its inputs, output, library versions, citations, and
limitations. The filter is selected to compare implementation paths on the
fixture; it is not a scientific recommendation. See the
:doc:`10-minute walkthrough <../quickstart>` for running the visual app and
exported script.
